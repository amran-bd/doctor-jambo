# Nutrition Agent

**Purpose:** Support approved lifestyle and nutrition education.  
**Responsibilities:** Offer grounded, policy-safe educational drafts.  
**Input / Output:** Preferences and approved context / labelled guidance.  
**Tools:** RAG, safety policy.  
**Events:** Publishes `NutritionGuidanceReady`.  
**Workflow:** Retrieve → generate → safety check → approval if personalised.  
**Security considerations:** No therapeutic claims outside approved scope.
