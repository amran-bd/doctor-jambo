# Agentic AI ADRs

| ADR | Decision | Rationale |
| --- | --- | --- |
| ADR-AGENT-001 | Multi-agent architecture | Separate bounded responsibilities and policies. |
| ADR-AGENT-002 | Coordinator-led orchestration | Central correlation with distributed specialist execution. |
| ADR-AGENT-003 | Consent-aware layered memory | Separate ephemeral workflow state from durable health data. |
| ADR-AGENT-004 | Human-in-the-loop design | Preserve clinical accountability and control consequences. |
| ADR-AGENT-005 | MCP tool integration | Use typed, scoped, auditable tool access. |
