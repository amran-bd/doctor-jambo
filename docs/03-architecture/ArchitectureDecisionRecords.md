# Architecture Decision Records

| ADR | Decision | Rationale |
| --- | --- | --- |
| ADR-001 | Adopt microservices architecture | Independently scale and evolve domain capabilities. |
| ADR-002 | Adopt DDD | Preserve clear business ownership and avoid a shared healthcare model. |
| ADR-003 | Adopt event-driven architecture | Support resilient, asynchronous workflows and integration. |
| ADR-004 | Adopt Spring AI | Standardise governed Java/Spring model integration. |
| ADR-005 | Adopt RAG architecture | Ground AI responses in approved, traceable knowledge. |
| ADR-006 | Adopt agentic AI architecture | Coordinate bounded, auditable assistance with human control. |

Each ADR requires status, consequences, alternatives, and owner before implementation.
