# Bounded Contexts

| Context | Responsibilities |
| --- | --- |
| Identity | Authentication, authorisation, user management |
| Patient | Patient profile, health-information metadata, preferences |
| Doctor | Doctor profile, availability, consultation participation |
| Consultation | Patient-doctor interaction, lifecycle, medical notes |
| Medical Record | Medical history, documents, reports |
| AI | LLM interaction, prompt management, AI orchestration |
| RAG | Document ingestion, embedding, vector search, knowledge retrieval |
| Agent | Agent orchestration, workflow execution, multi-agent communication |
| Notification | Email, SMS, push notification and delivery status |
