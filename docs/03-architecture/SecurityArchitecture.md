# Security Architecture

OAuth2/OIDC authenticates users; JWTs propagate scoped identity; RBAC and least privilege enforce authorisation. Data is encrypted in transit and at rest. Audit logs record health-data access, consent, AI/agent actions, and privileged changes. Healthcare privacy requires data minimisation, purpose limitation, consent management, retention controls, and region-aware processing. AI tools and MCP access require explicit scopes and approval policy.
